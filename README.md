# モードプラス TOPデザイン確認版

2026-10-07。写真を主役にした、子どもと大人の両方に向けたTOPのローカル制作版。

## 編集対象

- `index.html`: TOPの文章、構成、写真、リンク。
- `home.css`: TOP専用のデザイン。既存下層の `styles.css` には影響しない。
- `home.js`: ロゴ導入、スクロール表示、モバイルメニュー。外部ライブラリなし。
- `img/renewal/`: 現行モードプラスの写真を軽量化したWebP。出典は `SOURCES.md`。

## 構成の根拠

受注済み「モードプラス_Webサイトリニューアル提案書_202609_改訂第7版」の7・8・12ページに基づく。

写真・短いコピー → 6コース → 実績 → 選ばれる理由 → 講師・子どもと大人の生徒様の声 → 2教室・お知らせ → 体験予約。

- PCは3列×2段、767px以下は2列×3段でコースを表示。
- グループのみ中間ページ。個人コースは詳細へ直接移動。
- クラス色は、さくらんぼ=ピンク、ぶどう=ラベンダー、いちご=赤、プレピアノ年少=水色、年中=緑。
- FAQの独立した新ページは未決定のため新設しない。フッターから現行FAQへ案内。
- 採用はフッターのみ。CMS方式の検討表示は設けない。
- デザイン参考は https://sistokyo.kansai-intlschool.jp/ 。写真やロゴの流用はしていない。
- LPコピーの確認観点を使い、最初に対象と6コースを伝え、途中の相談・最後の予約へつなげた。15セクションの一律追加は行わず、合意済みサイト構成を優先した。

## 動きと表示

- 初回はロゴを表示し、約0.8秒後にフェードして写真とコピーを表示。再生ボタンで再確認可能。
- 同一タブの再訪は待ち時間なし。`prefers-reduced-motion` では演出なし。
- JavaScriptが動作しなくても本文を表示。読み込み失敗時も3秒を上限にロゴ表示を解除。
- 写真は実際の既存素材。軽量形式・遅延読み込みを使用。肖像の加工や生成画像による置き換えなし。
