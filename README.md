## 構成の根拠

受注済み「モードプラス_Webサイトリニューアル提案書_202609_改訂第7版」の7・8・12ページに基づく。

写真・短いコピー → 6コース → 実績 → 選ばれる理由 → 講師・子どもと大人の生徒様の声 → 2教室・お知らせ → 体験予約。

- PCは3列×2段、767px以下は2列×3段でコースを表示。
- グループのみ中間ページ。個人コースは詳細へ直接移動。
- クラス色は、さくらんぼ=ピンク、ぶどう=ラベンダー、いちご=赤、プレピアノ年少=水色、年中=緑。
- FAQの独立した新ページは未決定のため新設しない。フッターから現行FAQへ案内。
- 採用はフッターのみ。CMS方式の検討表示は設けない。
- デザイン参考は https://sistokyo.kansai-intlschool.jp/ 。写真やロゴの流用はしていない。
- LPコピーの確認観点を使い、最初に対象と6コースを伝え、途中の相談・最後の予約へつなげた。15セクションの一律追加は行わず、合意済みサイト構成を優先した。

## 動きと表示

- 初回はロゴを表示し、約0.8秒後にフェードして写真とコピーを表示。再生ボタンで再確認可能。
- 同一タブの再訪は待ち時間なし。`prefers-reduced-motion` では演出なし。
- JavaScriptが動作しなくても本文を表示。読み込み失敗時も3秒を上限にロゴ表示を解除。
- 写真は実際の既存素材。軽量形式・遅延読み込みを使用。肖像の加工や生成画像による置き換えなし。

## FVデザイン比較（2026-10-07）

`fv-designs.html` が3案の比較入口。既存 `index.html` は変更せず、採用前の独立したデザイン案として追加。

- **A / 余白と親しみ**：写真に文字を重ねず、クリーム色・深緑・赤を使った明るいエディトリアル構成。子どもと大人のバランスがよい第一候補。
- **B / 音楽のリズム**：ピアノ・大人の歌・親子の3写真を曲線のある構図に配置。楽しさや幼児コースの親しみを強める方向。
- **C / 教室の空気感**：一枚のレッスン写真を大胆に見せ、白いコピー領域で人物の顔と文字を分離。写真の迫力を重視する方向。

比較画面の A/B/C、全幅/スマホ、ロゴ演出ボタンで確認可能。「別タブ」では比較UIなしで表示。単体ページを開くとロゴから始まり、比較の切り替え時は待ち時間を省く。低モーション設定では演出しない。

実装は `designs/fv-a.html`〜`fv-c.html` と各CSS、共通ヘッダー・ロゴ演出は `fv-common.css/js`、比較画面は `compare.css/js`。画像は前回採用済みの実写素材を再利用し、新しい画像取得や人物加工は行っていない。

コピーは短い見出し・対象者・体験予約の導線を優先するLPコピー確認観点で調整。今回の対象はFVのみのため、15セクションは増設せず、下部のコース案内は接続イメージに留める。採用後は従来の写真付き6コース以下のTOP構成へ統合する。コースの構成や運用方針は変更しない。

検証：`python3 scripts/check_fv_designs.py`（3案の構造・画像・アンカー・予約リンク・比較画面）、共通/比較JSの構文検査、実ブラウザで3案×8幅（320/390/640/768/960/1024/1440/1920px）の横はみ出し・見出し2〜3行を確認。デスクトップ・スマホ・タブレットの写真位置も視認確認。
